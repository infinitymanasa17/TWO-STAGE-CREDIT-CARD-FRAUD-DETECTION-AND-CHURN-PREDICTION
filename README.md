# TWO-STAGE-CREDIT-CARD-FRAUD-DETECTION-AND-CHURN-PREDICTION
💼 Fraud Detection & Churn Prediction System
This project combines machine learning and web development to address two key business challenges:

🔐 Fraud Detection

Built an XGBoost-based model to detect fraudulent credit card transactions with a high AUC of 0.99.

Introduced a two-stage validation system, including duplicate transaction detection (accuracy: 0.73) to improve model trustworthiness.

Integrated the model with a real-time Flask web app for intuitive user interaction and analysis.

📉 Churn Prediction

Developed a LightGBM model to predict customer churn, achieving AUC: 0.89.

Trained on behavioral features to enable proactive customer retention efforts.

Evaluated using ROC-AUC, precision, recall, and F1-score to ensure model robustness.

🚀 Tools & Technologies: Python, XGBoost, LightGBM, Flask, Pandas, Scikit-learn, Jupyter Notebook
📊 Key Metrics: Fraud AUC - 0.99 | Duplicate Detection Score - 0.73 | Churn AUC - 0.89
